# 自己动手改这座岛

入口是 `页面.html`，它引用本目录的三个脚本与样式表，直接双击也能预览。日常使用请打开文件夹外层的 **未名岛.html**，尽量保持同一个入口和浏览器。

- `app.js`：计时、待办、手记、统计、工具与本地存档。
- `scene.js`：用 Canvas 手绘的悬浮小岛，没有外部图片。
- `audio.js`：用 Web Audio 合成的雨、炉火与风。
- `style.css`：布局、色彩、字体、响应式与减少动态效果。
- `打包.py`：把上述源码合成外层的独立 HTML。

改完后，在本目录执行 `python 打包.py` 即可更新外层入口。打包只使用 Python 标准库，不联网、不安装依赖。运行这个应用本身不需要 Python。

数据保存在 `localStorage`，键名 `weiming-island-v1`。备份采用带有 `schema: weiming-island` 的 JSON；手记可单独导出为 Markdown。导入前会保留旧存档，损坏的存档也会尽量留下恢复副本。

这份源码完全在本地，随你修改。
