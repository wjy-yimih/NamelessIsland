# 未名岛

双击 **未名岛.html** 就能打开。无需安装、账号或网络；这个 HTML 已包含界面、声音和小岛，可以单独复制到另一台电脑。

里面有几样每天可能用得上的东西：

- 专注与休息计时、待办，以及会随专注慢慢生长的小岛。
- 按日期写手记，查看专注记录，导出手记。
- 晴夜、雨雪、晨光，和可以混合播放的环境声音。
- 文字统计、JSON 整理、Base64 / URL 编解码、随机选择。

首页空白处按 **空格** 开始或暂停计时；按 **Esc** 退出沉浸模式或关闭弹窗。右上角设置可修改岛名、专注时长和动态效果。

**数据需要单独带走。** 手记、待办和记录保存在当前浏览器里，不在 HTML 文件中。移动文件、更换电脑或浏览器、清理浏览器数据前，请在设置里点“导出备份”，再在新地方用“恢复备份”导入。重要记录请另存一份；无痕窗口不适合长期存档。

设置里的“找回之前的版本”可查找和导出本浏览器留下的旧存档，并恢复其中可用的版本，包括导入前的副本，以及异常存档、跨页面手记冲突留下的版本。它们也依赖当前浏览器，请及时导出需要的内容。

**源码** 文件夹提供可阅读和修改的源文件；其中的 Python 打包脚本供修改后重新生成 HTML 使用。日常打开小岛不需要 Python。

这个文件夹可以随意改名。岛的名字，也留给你。
